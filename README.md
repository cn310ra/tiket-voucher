# ▲ Triangle Sky Telomoyo — Coffee Shop & Sunrise Ticketing Ecosystem

Ekosistem antarmuka digital bertema **Specialty Coffee & Mountain Sunrise** untuk **Kafe Triangle Sky Telomoyo (Magelang, 1.894 mdpl)**, dirancang menggunakan pendekatan **Design Thinking** (Empathize, Define, Ideate, Prototype, Test).

## Struktur Antarmuka
1. **`index.html` — Aplikasi Pelanggan (Mobile-First)**: Pemesanan mandiri tiket sunrise rooftop Lt. 3, menu kopi hangat khas Telomoyo, status 3 lantai (pemanas Lt. 1, loket Lt. 2, kapasitas rooftop Lt. 3), serta klaim voucher `TRIANGLE10`.
2. **`kasir.html` & `js/kasir.js` — Aplikasi POS Kasir Lantai 2**: Antarmuka kasir cepat untuk jam sibuk subuh (04.30–06.30 WIB) dengan filter kategori, validasi voucher otomatis, multi-metode bayar (Tunai, QRIS, Debit), dan hitung kembalian instan.
3. **`manajer.html` — Dasbor Operasional Manajer**: Pemantauan omzet harian, tren kepadatan pengunjung per jam, performa menu kopi terlaris, serta indikator keamanan kapasitas rooftop kaca Lt. 3.
4. **`css/style.css` — Design System**: Palet warna *Warm Espresso & Sunrise Amber* (`#1E140F`, `#C86D3B`, `#E09F3E`, `#F7F3EE`) dengan elemen geometris segitiga (`▲`) khas arsitektur Triangle Sky.

## Cara Menjalankan
Buka langsung `index.html` di browser atau aktifkan **GitHub Pages** pada branch `main`.
