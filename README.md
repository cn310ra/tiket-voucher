# Tiket & Voucher - Triangle Sky Telomoyo

Prototype UI/UX website Tiket & Voucher untuk destinasi wisata Triangle Sky Telomoyo, Salatiga.

**Demo:** https://cn310ra.github.io/tiket-voucher/

## Halaman

| File | Peran | Deskripsi |
|------|-------|-----------|
| `index.html` | Pelanggan (mobile) | Beranda, menu kopi, beli tiket, voucher, dan profil |
| `kasir.html` | Kasir (POS) | Penjualan baru, ringkasan pesanan, dan pembayaran |
| `manajer.html` | Manajer (dasbor) | Ringkasan operasional penjualan dan tiket |

Setiap halaman memiliki bilah **Mode Review** di bagian atas untuk berpindah antar tampilan.

## Teknologi

React 18, Tailwind CSS, Lucide Icons (semua lewat CDN, tanpa proses build).

## Catatan

Ini adalah prototype desain, sehingga tidak semua tombol aktif dan data bersifat contoh.
